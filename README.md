# Helyesírás-gyakorló

Webes gyakorlóplatform gyerekeknek, elsőként helyesírással (1–8. osztály), diszgráfia-barát móddal. Később natív app és más tantárgyak (szorzótábla, nyelvtan, angol) ugyanazzal a feladatmotorral.
